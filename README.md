# 행복한 삶을 위한 가치관 정립하기

사회정서교육 수업용 학생 웹앱입니다. 학습지의 네 활동을 차례로 채우고, 마지막에 완성 카드를 이미지로 저장해 패들렛에 올립니다.

- 학생용 주소: https://cleveranawim-source.github.io/happy-values/
- 교사용 결과판: https://cleveranawim-source.github.io/happy-values/results.html (특정 반 바로 열기: `results.html?class=3-2`)
- 활동1 내 삶의 우선순위 밸런스 게임 · 활동2 핵심 가치 3개와 행복했던 경험 · 활동3 이미지 프리즘 카드(사진 또는 그림)로 행복한 삶 표현 · 마무리(배우고 느낀 점, 실천 사항, “내가 생각하는 행복은 ___ 이다.”)
- 학생이 적은 글·그림·사진은 학생 기기의 브라우저에만 저장됩니다.
- 학생이 첫 화면에서 학년·반을 고르면 **고른 답만**(딜레마 선택, 핵심 가치 이름) 익명 기기 번호와 함께 결과판으로 보냅니다. 이름·학번·이유·경험 글은 보내지 않습니다.

## 결과판 저장소

- Supabase 프로젝트 `classroom-board-test`의 `hv_responses` 표, `hv_submit`(보내기)·`hv_results`(집계) 함수. 표는 직접 읽을 수 없고 함수로만 씁니다.
- 무료 프로젝트는 오래 쓰지 않으면 일시정지될 수 있습니다. 결과판에 "불러오지 못했어요"가 뜨면 Supabase 대시보드에서 프로젝트를 다시 켜 주세요.

## 고치는 방법

1. `src/app.html`을 고칩니다.
2. `sh build.sh`로 `index.html`(Pages용)과 `행복한삶_가치관정립.html`(패들렛 파일용)을 다시 만듭니다.
3. 커밋하고 푸시하면 몇 분 뒤 학생용 주소에 반영됩니다.
