# 행복한 삶을 위한 가치관 정립하기

사회정서교육 수업용 학생 웹앱입니다. 학습지의 네 활동을 차례로 채우고, 마지막에 완성 카드를 이미지로 저장해 패들렛에 올립니다.

- 학생용 주소: https://cleveranawim-source.github.io/happy-values/
- 활동1 내 삶의 우선순위 밸런스 게임 · 활동2 핵심 가치 3개와 행복했던 경험 · 활동3 이미지 프리즘 카드(사진 또는 그림)로 행복한 삶 표현 · 마무리(배우고 느낀 점, 실천 사항, “내가 생각하는 행복은 ___ 이다.”)
- 적은 내용은 학생 기기의 브라우저에만 저장되며 서버로 보내지 않습니다.

## 고치는 방법

1. `src/app.html`을 고칩니다.
2. `sh build.sh`로 `index.html`(Pages용)과 `행복한삶_가치관정립.html`(패들렛 파일용)을 다시 만듭니다.
3. 커밋하고 푸시하면 몇 분 뒤 학생용 주소에 반영됩니다.
